# Ambrook for ChatGPT

The Ambrook plugin package for ChatGPT. It connects to the read-only [Ambrook MCP endpoint](https://api.ambrook.com/mcp) and contains the listing details, connection settings, and the `use-ambrook` skill for month-end briefings, unpaid invoices, bills due, and bookkeeping cleanup.

The connection is read-only. It can't create or edit records, send invoices, pay bills, or move money. An Ambrook account with MCP access is required.
